# luaia.com.br

Dashboard e backend para a plataforma luaia.com.br - Casa da Lua

## Estrutura

- `/dashboard` - Frontend Next.js
- `/cmd` - Scripts de comando
- `/cerebro-lua` - Sistema de memória

## Tech Stack

- **Frontend:** Next.js 14, React 18, TypeScript
- **Backend:** Node.js, Python
- **Infrastructure:** Casa da Lua (Kubuntu 24.04 LTS)

## Getting Started

```bash
# Dashboard
cd dashboard
npm install
npm run dev

# Backend
npm start
```
